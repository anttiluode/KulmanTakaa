The phone page actor.html moves a bright bar to a position chosen by a hash of the wall clock every 1.5 s. This page knows the same hash, so it can check whether what it recovered follows the bar. The orange bar is the correlation; the red tick is the best any of 40 wrong schedules reaches on the same data with the same lag search. Only the orange passing the red counts. Run the phone in Slots or Colour; to test the null, run it in Still or Off and the orange must stay below red.

Bench & record

The simulation is a camera standing back along a wall, looking at the floor near its edge. A bar of light moves in the hidden corridor; the camera never sees it, only the floor does. Same code path as the real camera.

Saves the per-angle floor brightness of every frame as JSON, for offline re-analysis (node tools/analyze.cjs run.json).
